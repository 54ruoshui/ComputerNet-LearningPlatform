## 四、关键缺陷与修复验证

### 4.1 ReAct 工具调用静默失效（已修复，2026-09-23）

- **现象**：glm-4-flash 长期不返回 tool_calls，检索从未介入，graph_data 恒为空；
- **影响**：早期对比实验的"系统"臂实为无检索直答，数据无效；
- **修复**：主模型切换 glm-4-flash-250414 + Agent 预检索兜底（无 tool_calls 时自动检索并重答，`retrieval_fallback` 标记）；
- **验证**：复现脚本 + 重跑对比实验，SSE 恢复 `graph` 事件；
- **详见**：《已知问题-ReAct工具调用失效.md》。
