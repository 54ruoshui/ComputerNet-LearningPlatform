# 基于 Qwen3-8B 的计算机网络教学问答模型微调实验报告

> 项目：GraphRAG 计算机网络教学系统（大创项目）
> 实验周期：2026-09-11 ~ 2026-09-12
> 算力环境：AutoDL RTX 4090（24GB）单卡 / LLaMA-Factory

---

## 一、实验目标

在现有 GraphRAG 教学系统（Neo4j 知识图谱 + LangGraph Agent + glm-4-flash）基础上，通过监督微调（SFT）获得一个**以教材为本、教学风格可控**的计算机网络问答模型，作为系统答案生成端的候选替代方案。

需要回答的核心问题：

1. 微调能否让模型对齐教材的知识表述与教学风格？
2. 微调是否会造成通用知识能力退化（灾难性遗忘）？
3. 微调的收益体现在哪些可量化的维度上？

---

## 二、数据集

### 2.1 构成

| 数据集 | 形态 | 样本数 | system prompt |
|---|---|---|---|
| ComputerNet_2 | 单轮问答 | 3,839 | 无 |

- `cutoff_len=4096` 下两数据集截断率均为 0.0%

## 三、训练方案

### 3.1 基座模型选择

选择 **Qwen3-8B**（Apache 2.0）的理由：中文能力最强的 7-8B 档开源模型之一；微调生态成熟（LLaMA-Factory/ms-swift 开箱支持）；原生 32K 上下文覆盖数据中最长样本；与项目现有 Qwen embedding 技术栈一致。

### 3.2 超参数

| 参数 | 值 | 说明 |
|---|---|---|
| 微调方法 | LoRA | rank=16, alpha=32, dropout=0, target=all-linear |
| 可训练参数 | 43,646,976（0.53%） | 全参数 8,234,382,336 |
| 学习率 | 1e-4，cosine 衰减，warmup_ratio 0.1 | |
| 轮数 | 3.0 | |
| 批大小 | 2 × 梯度累积 8 = 等效 16 | |
| 截断长度 | 4,096 | 数据实测 0% 截断 |
| 精度 | bf16 + 梯度检查点 + Liger Kernel | |
| enable_thinking | False（训练与推理一致） | 数据无思维链，避免空 `<think>` 计入 loss |
| 量化 | 无 | 24GB 足以支撑 bf16 LoRA |

### 3.3 关键工程问题及解决（可复现记录）

| 问题 | 现象 | 解决 |
|---|---|---|
| 镜像源 401 | hf-mirror 无法代理 HF 新 Xet 存储协议 | `HF_HUB_DISABLE_XET=1` 强制 HTTP 下载 |
| 首步 OOM | Qwen3 词表 15.2 万，交叉熵需落地完整 logits（batch 2×4096×151936 ≈ 5GB），梯度检查点无法覆盖 | 引入 **liger-kernel** 融合线性交叉熵，省出峰值显存 |
| 显存余量 | 8B 权重 bf16 占 16GB | 梯度检查点开启后峰值稳定在 18~19GB |

### 3.4 训练结果

| 指标 | 值 |
|---|---|
| 总步数 | 1,455（485 步/epoch × 3） |
| 耗时 | 5 小时 14 分（RTX 4090） |
| 费用 | 约 ¥10（AutoDL 按小时计费） |
| train_loss（全程均值） | 1.0795 |
| loss 轨迹 | 起点 1.81 → 前 1/4 均值 1.25 → 后 1/4 均值 0.99 → 收敛于 ~1.0 |
| 训练产物 | `qwen3-8b-cnnet-lora`（LoRA 权重 167MB + 配置/tokenizer/日志） |

loss 收敛于 1.0 附近而非更低，符合知识问答类数据的固有熵（同一问题存在多种合理表述），未出现过拟合迹象（loss 未逼近 0，无震荡）。

## 四、评估设计

为同时回答"是否退化"与"是否有收益"，设计两组互补评测：

### 4.1 客观评测：选择题正确率（回答"是否退化"）

- **题目来源**：项目自有题库（Neo4j MCQuestion 节点，共 305 题）
- **抽样**：按 OSI 五层分层抽样 101 题（物理层 21 / 数据链路层 14 / 网络层 23 / 传输层 24 / 应用层 19）
- **偏斜控制**：原题库正确答案 B 占 64%（全选 B 即得 63 分），评测前对每题选项随机重排，重排后答案分布 A:30 / B:24 / C:13 / D:34，随机基线 25%
- **生成设置**：贪婪解码（可复现）、仅输出字母、max_new_tokens=32、两模型使用完全相同的提示词
- **判分**：正则提取首个选项字母，自动判分

### 4.2 定性评测：开放问答对比（回答"收益在哪"）

- 8 道覆盖传输层/网络层/应用层的专业问题，教学 system prompt 与训练数据一致
- 两模型相同输入、贪婪解码，输出供逐题对比

## 五、评估结果

### 5.1 选择题正确率：持平，无灾难性遗忘

| 模型 | 物理 | 数据链路 | 网络 | 传输 | 应用 | **总体** |
|---|---|---|---|---|---|---|
| 基座 Qwen3-8B | 86% | 86% | 87% | 83% | 100% | **88.1%**（89/101） |
| 微调版（LoRA） | 86% | 86% | 87% | **88%** | 100% | **89.1%**（90/101） |

逐题差异分析：

| 类别 | 数量 | 明细 |
|---|---|---|
| 两模型都错 | 10 | 多为易混淆概念题 |
| 仅微调版答对 | 2 | 传输层 1 题、网络层 1 题 |
| 仅基座答对 | 1 | 网络层 1 题 |
| 无效输出 | 0 | 两模型指令遵循均完好 |

**结论**：+1 题的差距（89 vs 90）在 101 样本下统计上等价于持平。该实验的客观结论是：**微调没有损害模型的事实性知识能力**（含全部 5 个 OSI 层），传输层（训练数据重点章节）小幅 +5 个百分点但样本量不足以显著。

### 5.2 开放问答：三类稳定改进

逐题对比 8 组回答后，观察到微调版三类可复现的优势，各选一个典型案例（完整原文见 `finetune/eval/qa_showcase.json`）：

**① 命中教材标准答案**（TCP 三次握手为什么不能两次）
教材标准答案为"防止已失效的连接请求报文段误建连接"。微调版精确复现了该论证路径（失效 SYN → 服务器误建连接 → 第三次握手消除歧义）；基座版答的是"报文丢失/确认丢失"，未命中考点。

**② 机制描述更精确**（慢启动 vs 拥塞避免）
微调版给出精确因果链"每收到一个 ACK，cwnd +1 MSS → 每 RTT 翻倍（1,2,4,8…）→ 达到 ssthresh 后每 RTT +1 MSS 线性增长"；基座版将两种增长口径混写在同句，并把"三个重复 ACK"（快恢复，不回慢启动）与"超时"（回慢启动）的处理混为一谈。

**③ 教学表达去模板化、信息密度更高**（ARP 协议与 ARP 欺骗）
微调版讲清攻击可行的根因（ARP 协议无认证机制）并给出 DAI 的具体验证逻辑；基座版为满足回答模板在三个小节各插入一段重复的"咖啡店"类比。微调版还主动关联了"隔离冲突域"等教材知识点。

**④ 领域深度**（双向鉴别协议中的不重数——本数据集重点领域）
微调版以"挑战—响应"协议视角解释 nonce 防重放机制及攻击成立条件；基座版列举攻击类型但表述空泛（如"中间人插入自己生成的 nonce"未说明为何成立）。

### 5.3 对抗性观察：回答长度的变化

| 模型 | 8 题开放问答平均回答长度 |
|---|---|
| 基座 Qwen3-8B | 约 1,133 字 |
| 微调版（LoRA） | 约 731 字 |

微调后回答**有意变短**（-36%），这是训练数据分布（回答中位 315~765 字、无一超 2000 字）的直接体现，属于风格对齐而非能力缺陷——所有回答均为自然收尾、要点完整。若需要更长的详解风格，应从数据端调整后重训，而非推理端调参。

### 5.4 综合对比总表

| 维度 | 基座 Qwen3-8B | 微调版 | 判定 |
|---|---|---|---|
| 选择题正确率（101 题） | 88.1% | 89.1% | 持平（无退化） |
| 教材标准答案命中 | 部分题未命中考点 | 命中 | **微调优** |
| 机制表述精确性 | 存在口径混同 | 因果链清晰 | **微调优** |
| 教学风格 | 模板化、类比堆砌 | 递进式、关联教材 | **微调优** |
| 回答长度 | 偏长（~1100 字） | 适中（~730 字） | 取决于应用场景 |
| 输出可控性 | 随 system prompt 波动 | 稳定遵循教学人设 | **微调优** |

## 六、结论

1. **风格与教材对齐**：微调成功将通用模型转变为"以教材为本、定义→类比→机制递进、关联知识点"的教学风格，这正是 GraphRAG 教学系统答案生成端需要的可控性。
2. **无知识退化**：分层抽样的选择题评测证明五个 OSI 层的正确率均持平，排除灾难性遗忘。
3. **重点领域表述修正**：传输层（TCP 拥塞控制）与安全鉴别等训练数据重点章节上，微调版修正了基座的事实性/口径性瑕疵，是超出"风格对齐"之外的实质收益。
4. **成本可行**：全流程（下载→训练→评测）单卡 4090 一天内完成，训练成本约 ¥10，验证了大创项目预算下小规模领域 SFT 的可行性。

## 七、局限与后续工作

1. 训练数据 7,753 条全部为教学问答，未包含工具调用样本，直接放入 LangGraph Agent 可能削弱其 tool-calling 能力，后续可混入多轮工具调用数据再训；
2. 未划分独立验证集，loss 与选择题评测均为训练分布内评估，严格做法应留出 hold-out 集；
3. 单随机种子、单组超参（rank16/lr1e-4），未做消融实验；
4. 开放问答对比为定性分析（典型案例法），后续可用 LLM-as-Judge 盲评补充定量数字；
5. LoRA 尚未合并导出为独立模型，接入 GraphRAG 前需经 LLaMA-Factory Export 合并。
