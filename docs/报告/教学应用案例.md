# 教学应用案例

> 项目：基于 AIGC 的动态课程内容生成
> 对应申报书预期成果："形成 2-3 个教学应用案例：针对计算机网络课程的核心章节，设计个性化答疑、智能复习推送、动态实验方案等应用案例"
> 以下三个案例均基于系统现有功能撰写，操作路径可直接复现。

## 案例一：个性化答疑 ——「薄弱知识感知的 GraphRAG 答疑」

### 使用场景

《计算机网络》"运输层"章节（教材第 5 章）是历年挂科重灾区。学生自学 TCP 拥塞控制时提出："慢启动和拥塞避免有什么区别？为什么刚建立连接时发得慢？" 传统搜索引擎式的通用大模型回答泛泛而谈，不区分提问者当前水平；本系统在答疑时会感知该生对相关知识点的掌握状态，输出"讲给当前的他听"的答案。

### 操作步骤

1. 学生在首页（`/`）确认浏览器为同一会话（首页自动创建 session，跨页面共享）；
2. 先在 `/quiz` 做几道传输层题目（如答错"三次握手"相关题）；
3. 在首页输入问题"慢启动和拥塞避免有什么区别？"；
4. 观察答案气泡右侧的图谱视图：SSE 流式返回检索到的子图（TCP、拥塞控制等实体及关系）；
5. 对答案点击 👍/👎 提交满意度（计入试用评估与对比实验数据）。

### 系统支撑机制

- **检索约束生成**：ReAct Agent 发起 `knowledge_search` → 混合检索（Qwen 关键词提取 + 1024 维向量语义检索 + Cypher 关键词匹配）从 5 层 OSI 图谱取回权威上下文，答案基于教材知识而非模型记忆，抑制幻觉；
- **个性化注入**：`MasteryService.build_mastery_context()` 将该会话的掌握状态与遗忘预警写入 Agent 提示词——对已掌握实体简讲、对薄弱实体展开并关联其错题涉及的相邻知识点；
- **可解释性**：答案附带检索子图（D3 力导向图），学生可核对答案依据；
- **质量兜底**：若模型本轮未发起工具调用，预检索兜底自动介入（响应带 `retrieval_fallback` 标记），保证领域问题必有检索支撑。

### 预期效果

答疑内容与教材知识图谱对齐（对比实验：知识覆盖度 76.8% vs 通用大模型直答 64.6%，+12.2pp）；相同问题对不同掌握状态的学生呈现不同详略与侧重，实现"千人千面"的答疑解析。

## 案例二：智能复习推送 ——「艾宾浩斯曲线驱动的到期复习」

### 使用场景

期末复习周，学生两周前学的"数据链路层"差错协议（CSMA/CD、停止-等待协议）已遗忘大半，但不知道该复习什么、什么时候复习。本系统根据其答题记录自动计算每个知识点的最佳复习时点并推送。

### 操作步骤

1. 学生平时在 `/quiz` 刷题、`/quiz` 试卷 tab 做 408 真题——每次作答（无论对错）都作为一次"复习事件"记入遗忘曲线模型；
2. 复习周打开 `/review` 页：系统展示**今日到期知识点队列**（按预测保留率最低排序）与**未来 7 天复习负荷**，学生按队列逐个自评回忆质量（想起来了/想不起来）；
3. 复习若干天后打开 `/dashboard`：查看掌握度分布、各章节正确率热力图与 LLM 生成的学习报告，确认薄弱章节是否改善；
4. 学生也可在 `/quiz` 试卷 tab 完成一次真题后点击"针对性练习"，系统基于薄弱点画像（层次/难度/章节三维）加权推荐 20 题。

### 系统支撑机制

- **掌握度衰减模型**：R(t) = e^(-ln2·t/S)，每个学生×每个知识点维护独立半衰期 S；
- **目标保留率驱动调度**：预测保留率降到 R*=0.90 时安排复习（interval = S·log₂(1/R*)），既不浪费时间也不过度遗忘；
- **间隔效应**：提取越困难（R 越低）的成功回忆带来的稳定性增益越大（S' = S×(1+5.0×(1-R)×q×EF/2.5)），符合"合意困难"学习科学结论；
- **自动掌握判定**：S≥504h 且复习≥3 次且质量≥4 的知识点自动标记掌握，退出复习队列；
- **闭环联动**：复习/答题事件同步更新掌握度 → 掌握状态注入案例一的答疑提示词 → 仪表盘聚合呈现。

### 预期效果

复习从"盲目翻书"变为"按遗忘曲线精准到点"：到期才复习、快忘先复习；7 天负荷预测帮助学生摊平复习压力；教师可通过班级薄弱点分布调整课堂重点。

## 案例三：AI 动态习题生成 ——「图谱约束的按需出题与题库扩充」

### 使用场景

教师发现"网络层"子网划分（CIDR）题型学生错误率高，但现有题库该知识点题目数量不足，人工命题耗时。同时班级里有学生提前学完了，需要更高难度的拓展题。本系统支持从图谱实体种子按需生成符合学科逻辑的题目，经人工审核后入库。

### 操作步骤

1. 教师打开 `/quiz` 页底部的"AI 生成题目"面板；
2. 配置：层次=网络层、难度=hard、数量=5、种子实体填 `CIDR, 子网掩码, 路由聚合`；
3. 点击"生成题目"：LLM 以这些图谱实体为种子生成 MCQ（含四个选项、正确答案、解析、参考知识点）；
4. 在预览区逐题审阅、可直接编辑题干/选项/解析，勾选合格题目；
5. 点击"确认入库"：入库题目带 `source:'ai'` 标记，`references` 指回图谱实体（自动建立 `ABOUT` 边），立即进入刷题池供学生练习。

### 系统支撑机制

- **图谱种子约束**：生成提示词携带实体名称、类型、层次与描述，要求题目紧扣给定知识点，降低跑题与幻觉；
- **raw JSON 模式 + 逐题校验过滤**：解析失败的题目自动剔除，仅保留结构合法的候选；
- **人工审核闸门**："生成→预览→确认入库"三段式，AI 只产出候选，教师把关质量（生成不入库，审核后才入库）；
- **来源可追溯**：`source:'ai'` 区分人工/AI 题目，`ABOUT` 边使新题自动进入对应层次的刷题筛选与错题诊断链路；
- **层命名兼容**：MCQ「传输层」与图谱「运输层」经 `LAYER_ALIASES` 双向兼容，保证 ABOUT 边正确建立。

### 预期效果

题库从静态 414 题扩展为可按需增长的动态资源：教师按教学缺口定向补题（分钟级 vs 人工小时级）；生成的题目自带解析与知识点关联，直接融入刷题、错题、复习调度与薄弱点分析闭环，体现申报书"课程内容自动生成与动态迭代"的核心目标。
