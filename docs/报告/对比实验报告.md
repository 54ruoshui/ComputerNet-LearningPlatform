## 一、实验目标

依据《基于AIGC的动态课程内容生成》项目申报书要求，将本系统（GraphRAG 混合检索 + 知识图谱上下文 + ReAct Agent）与通用大模型直接生成方案对比，从**回答准确性、知识覆盖度、学生满意度**三个维度进行量化评估。

## 二、评测设计

| 维度 | 指标 | 说明 |
|---|---|---|
| 准确性 | 客观题准确率 | 50 道选择题（MCQuestion，按 OSI 层分层抽样），正则解析回答中的选项字母 |
| 知识覆盖度 | 实体覆盖率 | 开放问答答案提及的图谱实体 ∩ 题目 ABOUT 关联实体 ÷ 关联实体数（20 题） |
| 知识覆盖度 | 检索命中率（仅系统） | 检索返回实体 ∩ ABOUT 关联实体 ÷ 关联实体数 |
| 回答质量 | LLM 盲评 | 评判模型 win/tie/loss 三分类，随机交换答案位置消除位置偏差 |
| 学生满意度 | 用户反馈 | 答题界面 👍/👎 采集（`answer_feedback` 表） |

## 八、结论与局限

局限：

3. 覆盖度指标依赖图谱实体命名匹配，同义表述（如中英文别名）可能被低估；
4. 满意度来自真实试用积累，样本量随试用推进增加。
