# GraphRAG 系统部署指南

> 目标环境：云服务器裸机部署（Ubuntu 22.04 / 24.04）+ 服务器自建 Neo4j + 域名 HTTPS 访问
>
> 适用架构：FastAPI(5001) + Neo4j(localhost:7687) + Nginx 反代 + systemd 守护

## 0. 部署架构总览

```
用户浏览器 ──HTTPS(443)──> Nginx ──HTTP(127.0.0.1:5001)──> FastAPI 应用
                                                              │
                                                              ├──> Neo4j (127.0.0.1:7687, 仅本机)
                                                              ├──> ZhipuAI API (LLM, 外网)
                                                              └──> DashScope API (Qwen 向量/关键词, 外网)
```

要点：

- Neo4j 只监听 `127.0.0.1`，不暴露公网（应用与 Neo4j 同机）
- 应用跑在 conda 环境里，由 systemd 守护，开机自启
- Nginx 负责 HTTPS 终止和反向代理，SSE 流式输出需特殊配置
- 本地数据（会话记忆、掌握度、错题本）存放在 `data/` 目录，迁移时需一并复制

## 1. 前置准备

### 1.1 服务器规格建议

| 项目 | 最低 | 建议 |
|------|------|------|
| CPU | 2 核 | 2 核 |
| 内存 | 4 GB | 8 GB（Neo4j + Python + JVM 合计约 2~3 GB） |
| 磁盘 | 20 GB | 40 GB SSD |
| 系统 | Ubuntu 22.04/24.04 LTS | 同左 |

### 1.2 域名与安全组

1. 在域名服务商处添加 A 记录：`graphrag.example.com → 服务器公网 IP`
2. 云控制台安全组放行端口：`22`（SSH）、`80`（HTTP）、`443`（HTTPS）
3. **不要**放行 `5001`、`7474`、`7687`

### 1.3 本地打包项目

在 Mac 上执行（若使用 git 远程仓库可跳过，直接服务器上 clone）：

```bash
cd ~/Projects/aigc
# 排除 .env（含密钥）、虚拟环境、缓存，避免污染服务器
rsync -avz --exclude '.env' --exclude '__pycache__' --exclude '.git' \
  ~/Projects/aigc/ user@服务器IP:/tmp/aigc/
```

## 2. 服务器基础环境

SSH 登录服务器后，按顺序执行。

### 2.1 系统更新与基础工具

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget git unzip build-essential
sudo timedatectl set-timezone Asia/Shanghai
```

### 2.2 安装 Java 17（Neo4j 依赖）

```bash
sudo apt install -y openjdk-17-jdk
java -version   # 确认输出 17.x
```

### 2.3 安装 Neo4j Community

```bash
# 添加 Neo4j 官方源（以 5.x LTS 为例）
wget -O - https://debian.neo4j.com/neotechnology.gpg.key | sudo gpg --dearmor -o /usr/share/keyrings/neo4j.gpg
echo 'deb [signed-by=/usr/share/keyrings/neo4j.gpg] https://debian.neo4j.com stable 5' | sudo tee /etc/apt/sources.list.d/neo4j.list
sudo apt update
sudo apt install -y neo4j
```

> 版本说明：代码中向量检索优先使用新版 `db.index.vector.search`（Neo4j 2026.01+），失败自动回退到 5.x 的 `db.index.vector.queryNodes`，因此 5.x 与 2026.x 均可正常工作。

### 2.4 安装 Miniconda 并创建 aigc 环境

```bash
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh -b -p $HOME/miniconda3
$HOME/miniconda3/bin/conda init bash
exec bash    # 重新加载 shell

conda create -n aigc python=3.12 -y
conda activate aigc
```

> 项目要求 Python `>=3.9, <3.14`，3.12 稳定可用。

### 2.5 安装 graphviz（知识图谱图片生成依赖）

```bash
sudo apt install -y graphviz
```

## 3. 初始化 Neo4j

### 3.1 设置初始密码

```bash
# 停掉服务后设置初始密码（替换为你自己的强密码）
sudo systemctl stop neo4j
sudo neo4j-admin dbms set-initial-password '你的强密码'
sudo systemctl start neo4j
sudo systemctl enable neo4j
```

### 3.2 验证连接

```bash
cypher-shell -u neo4j -p '你的强密码' "RETURN 1;"
# 应输出 1
```

### 3.3 保持仅本机监听（安全默认，无需修改）

默认配置已只监听 `localhost:7474` / `localhost:7687`，**不要**改监听地址——应用与 Neo4j 同机，走 `bolt://localhost:7687` 即可。可确认一下：

```bash
grep -E "listen_address|listen" /etc/neo4j/neo4j.conf | grep -v "^#"
# 默认应是 localhost:7687 / localhost:7474
```

## 4. 部署应用代码

### 4.1 放置代码

```bash
sudo mkdir -p /opt/aigc
sudo chown $USER:$USER /opt/aigc
rsync -avz --exclude '.env' --exclude '__pycache__' /tmp/aigc/ /opt/aigc/
cd /opt/aigc
```

### 4.2 安装 Python 依赖

```bash
conda activate aigc
pip install -r requirements.txt
```

### 4.3 创建 .env 配置

```bash
cat > /opt/aigc/.env <<'EOF'
# ===== Neo4j（必填）=====
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=你的Neo4j密码

# ===== ZhipuAI LLM（必填）=====
ZHIPUAI_API_KEY=你的智谱APIKey
ZHIPUAI_MODEL=glm-4-flash

# ===== Qwen（必填：向量嵌入 + 关键词提取都依赖它）=====
QWEN_API_KEY=你的阿里云DashScope APIKey
QWEN_EMBEDDING_MODEL=text-embedding-v3
QWEN_CHAT_MODEL=qwen-turbo

# ===== Web =====
WEB_HOST=127.0.0.1
WEB_PORT=5001
DEBUG=false

# ===== 鉴权：务必留空！=====
# 前端目前没有实现 X-API-Key 请求头，设置 API_KEY 后所有页面 API 调用会 401
API_KEY=

# ===== 日志 =====
LOG_LEVEL=INFO
LOG_FORMAT=console
EOF
chmod 600 /opt/aigc/.env
```

配置说明：

| 变量 | 必填 | 说明 |
|------|------|------|
| `NEO4J_URI` | ✅ | 同机部署用 `bolt://localhost:7687` |
| `NEO4J_PASSWORD` | ✅ | 上一步设置的密码 |
| `ZHIPUAI_API_KEY` | ✅ | LLM 推理 |
| `QWEN_API_KEY` | ✅ | 语义检索向量化 + 关键词提取，缺了语义搜索静默降级 |
| `API_KEY` | ⚠️ | **必须留空**（见上方注释），公网安全暂时依赖限流中间件 |

### 4.4 本地启动冒烟测试

```bash
cd /opt/aigc && conda activate aigc
python run.py --mode web
# 看到 "Uvicorn running on http://127.0.0.1:5001" 即成功，Ctrl+C 停止
```

## 5. 导入知识图谱数据

### 5.1 复制图谱数据文件

从 Mac 复制（`data/layers/` 下是分层 JSON，`cross_layer.json` 是跨层关系）：

```bash
# 在 Mac 上执行
rsync -avz ~/Projects/aigc/data/ user@服务器IP:/tmp/aigc-data/
# 在服务器上执行
rsync -avz /tmp/aigc-data/ /opt/aigc/data/
```

### 5.2 导入节点与关系

```bash
cd /opt/aigc && conda activate aigc
python scripts/build_from_json.py           # 全量导入
python scripts/build_from_json.py --stats   # 验证：查看实体/关系统计
```

### 5.3 生成向量嵌入

该脚本会**自动创建向量索引**（`entity_embedding_index`，cosine，1024 维）并为所有 Entity 节点生成 embedding：

```bash
python scripts/generate_embeddings.py
# 节点多时可用 --batch-size 控制批量大小
```

> 顺序不能反：先 build（建节点）→ 再 generate_embeddings（建索引 + 写向量）。
> 此步骤调用 DashScope API，需保证 `QWEN_API_KEY` 有效且有余额。

### 5.4 验证检索链路

```bash
python run.py --mode test
# 应能看到图谱统计 + 测试问题的正常回答
```

## 7. systemd 守护与开机自启

创建服务文件：

```bash
sudo tee /etc/systemd/system/graphrag.service > /dev/null <<'EOF'
[Unit]
Description=GraphRAG Computer Network Q&A System
After=network.target neo4j.service
Wants=neo4j.service

[Service]
Type=simple
User=你的用户名
WorkingDirectory=/opt/aigc
ExecStart=/home/你的用户名/miniconda3/envs/aigc/bin/python run.py --mode web
Restart=on-failure
RestartSec=5
# 环境继承自 .env（pydantic-settings 从 WorkingDirectory 下读取）
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
EOF
```

启动：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now graphrag
sudo systemctl status graphrag        # active (running) 即成功
journalctl -u graphrag -f             # 查看日志
```

> 注意：保持**单进程**运行（systemd 里不要配置多 worker）。会话记忆基于 SQLite checkpoint，多进程会互相竞争同一 db 文件。

## 8. Nginx 反代 + HTTPS

### 8.1 安装 Nginx 与 certbot

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
```

### 8.2 配置反代

```bash
sudo tee /etc/nginx/sites-available/graphrag > /dev/null <<'EOF'
server {
    listen 80;
    server_name graphrag.example.com;   # 换成你的域名

    location / {
        proxy_pass http://127.0.0.1:5001;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 流式输出关键配置
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
    }
}
EOF

sudo ln -s /etc/nginx/sites-available/graphrag /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

> SSE 三件套 `proxy_buffering off` + `proxy_read_timeout` + `proxy_send_timeout` 必须保留，否则前端流式回答会卡住或中途断开。

### 8.3 签发 HTTPS 证书

```bash
sudo certbot --nginx -d graphrag.example.com
# 按提示选择自动跳转 HTTPS（redirect）
```

certbot 会自动改写 Nginx 配置并设置证书续期（`systemctl status certbot.timer` 可确认自动续期已启用）。

### 8.4 防火墙收口

```bash
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable
sudo ufw status    # 确认只有 22/80/443
```

## 10. 常见问题

### Q1：语义检索返回空 / 回答"未在知识图谱中找到相关内容"

向量索引缺失或 embedding 未生成。检查：

```bash
cypher-shell -u neo4j -p '密码' "SHOW INDEXES;"
# 应看到 entity_embedding_index (VECTOR)
```

没有则重新执行 `python scripts/generate_embeddings.py`。

### Q2：前端图标白块

系统代理/CDN 问题导致 cdnjs 图标加载失败，硬刷新（Ctrl+Shift+R）可恢复；服务器端一般不受影响。

### Q3：流式回答中途断开

检查 Nginx 配置是否保留 `proxy_buffering off` 与超时设置（见 8.2）。

### Q4：设置 API_KEY 后页面全部 401

前端尚未实现 `X-API-Key` 请求头，公网部署请保持 `API_KEY` 留空（依赖限流中间件）；若要开启鉴权，需先给 `static/js/integrated-app.js` 和 `quiz-app.js` 的所有 fetch 统一加上请求头。

### Q5：Neo4j 连接失败

- 确认 `NEO4J_PASSWORD` 与 `neo4j-admin dbms set-initial-password` 设置的一致
- `ss -tlnp | grep 7687` 确认 Neo4j 已监听
- 确认 `.env` 在 `/opt/aigc/` 下（pydantic-settings 按工作目录读取）

### Q6：内存不足

Neo4j 默认堆内存约 1G+，Python 应用约几百 MB。4G 内存服务器建议：

```bash
sudo tee -a /etc/neo4j/neo4j.conf > /dev/null <<'EOF'
server.memory.heap.initial_size=512m
server.memory.heap.max_size=1g
server.memory.pagecache.size=512m
EOF
sudo systemctl restart neo4j
```

### Q7：更新代码后如何上线

```bash
# Mac 上
rsync -avz --exclude '.env' --exclude '__pycache__' --exclude 'data/' \
  ~/Projects/aigc/ user@服务器IP:/tmp/aigc-update/
# 服务器上
rsync -avz --exclude '.env' --exclude 'data/' /tmp/aigc-update/ /opt/aigc/
cd /opt/aigc && conda activate aigc
pip install -r requirements.txt     # 如有新依赖
sudo systemctl restart graphrag
```
